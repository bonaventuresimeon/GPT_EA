# 🛠️ Compile-Evidence Checklist

Use this checklist for the exact candidate that will enter release certification. It complements `METAEDITOR_COMPILE_GATE.md`; it does not replace MetaEditor.

## 🧬 Candidate identity
- [ ] Exact Git commit SHA recorded.
- [ ] Branch/tag recorded.
- [ ] Release validation ID recorded.
- [ ] Source path is the exact `GPT_EA.mq5` candidate.
- [ ] Source tree is clean or any intentional generated files are documented.
- [ ] No source change occurs after the certified compile without restarting the evidence cycle.

## 🖥️ Build environment
- [ ] Windows version/architecture recorded.
- [ ] MetaTrader 5 build recorded.
- [ ] MetaEditor build recorded.
- [ ] Compiler timestamp recorded in UTC.
- [ ] Terminal/broker build used for smoke load recorded.

## ⚙️ Compile execution
- [ ] Compile the exact `GPT_EA.mq5` in MetaEditor.
- [ ] All required `.mqh` includes resolve.
- [ ] Compile errors = **0**.
- [ ] Production compile warnings = **0**.
- [ ] No duplicate lifecycle callback definitions.
- [ ] No unresolved unsafe conversions/array/index warnings.
- [ ] No missing include/library/resource warnings.
- [ ] `.ex5` is freshly generated by this compile.

## 📄 Compiler log
- [ ] Full compile log archived as a plain text artifact.
- [ ] Log includes source path/build identity.
- [ ] Log belongs to the exact candidate SHA.
- [ ] Log contains final errors/warnings summary.
- [ ] Compile log SHA-256 recorded.

## 🔏 Artifact identity
- [ ] `GPT_EA.ex5` path recorded.
- [ ] EX5 SHA-256 computed after compile.
- [ ] EX5 timestamp is consistent with certified compile.
- [ ] Certified `.set` SHA-256 recorded, or literal `NONE` if no preset is used.
- [ ] No API key, MT5 password, proxy token or private signing key exists in the preset/package.

## 🚀 Load-smoke validation
- [ ] EX5 copied/available to the intended MT5 terminal.
- [ ] EA appears in Navigator.
- [ ] EA attaches to a demo chart.
- [ ] `OnInit()` completes without unresolved critical error.
- [ ] Experts/Journal show no load-time dependency failure.
- [ ] Real-account release gate remains blocked unless all external evidence is actually present.
- [ ] No trade is required for this smoke test.

## 🔐 R10 governance smoke check
- [ ] R7 API transport gate initializes.
- [ ] R8 legal/license gate initializes.
- [ ] R9 customer risk-acknowledgement gate initializes.
- [ ] R10 privacy sign-off gate initializes.
- [ ] Existing-position management paths are not disabled by release-gate blocking.

## 📦 Required evidence files

Recommended archive:

```text
artifacts/compile-evidence.json
artifacts/compile-evidence-validation.txt
artifacts/metaeditor-compile.log
artifacts/GPT_EA.ex5
artifacts/GPT_EA.ex5.sha256
artifacts/certified.set              # optional
artifacts/certified.set.sha256       # or explicit NONE
```

## 🤖 Machine-readable validation

Fill `COMPILE_EVIDENCE_TEMPLATE.json`, compute its canonical digest, then run:

```text
python tools/validate_compile_evidence.py artifacts/compile-evidence.json
```

The validator can verify formats, zero errors/warnings, required build identity, log existence, EX5/SET SHA-256 values when files are available, and the evidence-record digest.

## ⛔ Automatic compile NO-GO

Any of these invalidates compile certification:

- compile error > 0;
- production warning > 0;
- stale/missing EX5;
- source SHA mismatch;
- EX5 hash mismatch;
- compile log missing/mismatched;
- source changed after compile;
- smoke-load failure;
- secret discovered in the release preset/package;
- inability to establish artifact identity.

---

> 🛠️ **Rule:** no 0-error compile log + no exact EX5 identity = no live release certification.
